# Parking Lot

Use this file for technologies, papers, projects and ideas that are interesting but are not the current highest-priority learning node.

The purpose is not to suppress curiosity. It is to capture it without allowing it to replace the learning path.

## Rules

- Add the idea in one line.
- Note why it is interesting.
- Note which curriculum prerequisites it depends on.
- Revisit the parking lot after milestones, not during a focused learning session.
