# Pablo Learning Curriculum

This repository is not just a tutor configuration. It is the persistent learning system for building durable capability in software engineering, computer science, mathematics, machine learning and AI engineering.

## Priority order

1. **NVIDIA Level 6 AI Engineer apprenticeship** — formal spine and deadlines.
2. **Python fluency** — write and debug Python independently.
3. **Computer science fundamentals** — data structures, algorithms, memory, operating systems, networking and databases.
4. **Mathematics for ML** — algebra, probability/statistics, linear algebra and calculus/optimisation.
5. **Machine learning fundamentals** — classical ML through neural networks and transformers.
6. **Software engineering** — testing, APIs, databases, architecture, Git, Linux and production engineering.
7. **Applied AI engineering** — inference, fine-tuning, evaluation, RAG, agents, MLOps and deployment.

Interesting technologies that do not directly advance one of these tracks go into `curriculum/parking-lot.md` rather than replacing the current path.

## Rules for progression

A topic is not complete because it was discussed or explained.

Use these states:

- `not-started`
- `probing`
- `learning`
- `practising`
- `review-due`
- `mastered`

`mastered` requires evidence at all relevant levels:

1. **Recognition** — identify the correct idea.
2. **Recall** — explain it without prompts.
3. **Application** — solve a new problem using it.
4. **Production** — implement, debug or build something independently where applicable.

For programming topics, independent implementation is mandatory. AI may teach, review and give hints, but a mastery attempt should include an **AI-off phase** where Pablo writes the solution himself.

## Current phase

The first focus is deliberately narrow:

- Keep apprenticeship work current.
- Build Python fluency.
- Build CS foundations alongside Python.
- Introduce maths only as needed for the ML modules, then deepen it systematically.

Do not start a new major track merely because a new model, framework, agent system or infrastructure project looks interesting.
