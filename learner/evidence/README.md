# Evidence

This directory contains proof of learning, not notes about learning.

Create one file per assessed node, for example `python-a1-dictionaries.md`.

Each evidence file should record:

- date
- curriculum node
- task attempted
- whether AI assistance was allowed
- result
- mistakes/misconceptions
- what was corrected
- confidence after assessment
- next review date

## Evidence levels

### Recognition
Can identify the correct concept among plausible alternatives.

### Recall
Can explain or reconstruct the concept without being shown the answer.

### Application
Can use the concept in a new problem rather than repeating the teaching example.

### Production
Can independently build, implement or debug with it.

For programming topics, production evidence should normally include an AI-off attempt.

## Mastery rule

Do not mark a curriculum node mastered based on conversation quality, self-reported confidence or an AI-generated solution. Mastery requires demonstrated evidence appropriate to the node.
